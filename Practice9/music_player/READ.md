# Music Player 🎵

## Description

An interactive music player built with Pygame that allows users to control playback using keyboard inputs.

## Features

* Play, stop, next, and previous track controls
* Displays current track name
* Supports multiple audio files (WAV/MP3)
* Basic playlist management

## Controls

* **P** → Play
* **S** → Stop
* **N** → Next track
* **B** → Previous track
* **Q** → Quit

## How It Works

* Uses `pygame.mixer` for audio playback
* Tracks current song index in playlist
* Displays text using `pygame.font`

## Requirements

* Python 3.x
* pygame

## Run

```bash
python main.py
```
